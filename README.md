# 💕 Site romantique pour ma chérie

Un site rose et poétique avec :
- Une question piège "Voulez-vous vraiment voir ce site ?" avec... deux fois "Oui" 😏
- Vos photos entourant un poème au centre
- Une pluie de cœurs flottants

## 📸 Remplacer les photos

Placez vos photos dans le dossier `images/` en les renommant :
- `photo1.jpg` — Notre premier souvenir
- `photo2.jpg` — Ce sourire que j'adore
- `photo3.jpg` — Mon rayon de soleil
- `photo4.jpg` — À nos mille aventures

Astuce : si vos photos sont en `.png` ou `.jpeg`, soit renommez-les en `.jpg`, soit modifiez les noms dans `index.html` (lignes `<img src="images/...">`).

✏️ Vous pouvez aussi changer les légendes et le poème directement dans `index.html`.

## 🚀 Déploiement

1. **GitHub** : uploadez `index.html`, `style.css`, `script.js` et le dossier `images/` dans votre dépôt (via "uploading an existing file" ou avec `git push`).
2. **Netlify** : sur [app.netlify.com](https://app.netlify.com) → "Add new site" → "Import from Git" → choisissez votre dépôt → Deploy. C'est gratuit !
3. Partagez le lien (ou glissez-le dans vos papiers cadeaux 🎁).

Fait avec amour 💕
